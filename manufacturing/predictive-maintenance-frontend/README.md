# Predictive Maintenance Frontend

A React-based dashboard for monitoring industrial asset health and predictive maintenance recommendations.

## Tech Stack

- **React 18** with TypeScript
- **Vite** for build tooling
- **Tailwind CSS** for styling
- **shadcn/ui** for UI components
- **Axios** for API calls
- **Recharts** for data visualization

## Prerequisites

1. **Backend Server**: Make sure the FastAPI backend is running at `http://localhost:8000`
   ```bash
   # In the backend directory
   cd predictive_maintenance
   python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
   ```

2. **Node.js**: Version 16 or higher

## Setup Instructions

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Development Server

```bash
npm run dev
```

The application will be available at `http://localhost:3000`

### 3. Build for Production

```bash
npm run build
npm run preview
```

## Features

### File Upload Panel
- Upload sensor data CSV files
- Upload maintenance log CSV files (optional)
- File validation and error handling
- Upload progress and status feedback

### Risk Dashboard
- Real-time asset risk assessment
- Color-coded risk levels (Green/Yellow/Red)
- Responsive table that converts to cards on mobile
- Risk scores from 0-100 based on engineering logic

### Baseline vs Experiment Comparison
- Upload baseline + experiment datasets (CSV/XLS/XLSX)
- Deterministic comparison summary with signal-level deviations
- Engineering Copilot powered by Gemini with per-session memory of the comparison data

### DOE Validation
- DOE-ready baseline vs experiment validation with multi-agent backend
- Table-first analysis dashboard with stability flags
- Print-ready DOE report with confidence score and verdict
- Optional column mapping and time normalization inputs
- AI-requested plot scripts run via backend script runner

### Engineering Data Analyzer
- Single-dataset engineering analysis (profile → plan → execute)
- LLM proposes tests/plots (JSON only), Python computes numbers
- Plots generated by Python and rendered as images

### Key Design Principles

- **Clean & Industrial**: White/gray backgrounds, high contrast text
- **Professional**: No consumer-style animations or playful colors
- **Mobile-Responsive**: Works on phones, tablets, and desktops
- **Risk-Focused**: Color + number for risk visualization
- **Action-Oriented**: Clear maintenance verbs (Inspect, Replace, Monitor)

## API Integration

The frontend connects to the FastAPI backend at `http://localhost:8000`:

- `POST /upload` - Upload CSV or Excel files
- `POST /upload/batch` - Upload multiple sensor files with per-file analysis
- `POST /compare/upload` - Baseline vs Experiment comparison
- `POST /compare/copilot/query` - Ask the comparison copilot questions (Gemini-backed)
- `POST /doe/compare/upload` - DOE baseline vs experiment validation
- `GET /doe/report/{report_id}` - DOE report output
- `POST /analysis/plan` - Analyzer plan for single dataset
- `POST /analysis/run` - Execute analyzer plan
- `GET /analysis/report/{report_id}` - Analyzer report output
- `GET /risk_summary` - Get risk assessments
- `GET /health` - System health check

## Development

### Adding New Components

1. Use shadcn/ui components from `src/components/ui/`
2. Follow the established design patterns
3. Ensure mobile responsiveness

### API Calls

Use the centralized API client in `src/lib/api.ts`:

```typescript
import { apiClient } from '../lib/api';

// Get risk summary
const riskData = await apiClient.getRiskSummary();

// Upload files
const result = await apiClient.uploadData(sensorFile, maintenanceFile);

// Batch upload
const batchResult = await apiClient.uploadBatch(sensorFiles);
```

## Troubleshooting

### Backend Connection Issues
- Verify the backend is running at `http://localhost:8000`
- Check browser console for CORS errors
- Ensure both frontend and backend are running

### Build Issues
- Clear node_modules: `rm -rf node_modules && npm install`
- Check Node.js version: `node --version`

### TypeScript Errors
- Run type checking: `npm run build`
- Check import paths and type definitions
